# Seamwork 0.1.0

Seamwork 0.1.0 is the first release of the re-chartered C++23 project.

## What changed

- Seamwork is now a focused laboratory for interface and architecture refinement rather than a general-purpose utility library.
- The legacy libcoda aggregate/submodule graph has been retired from the active checkout.
- C++23 is the baseline for maintained code.
- The project now contains a catalog of design studies with documented alternatives, evidence, and deliberate non-promotions.
- Yahtsee provides the primary practical consumer path.
- The first promoted component is the narrow `seamwork::yahtsee` domain value contract.
- Pure parser boundaries have libFuzzer + ASan/UBSan qualification.
- The bounded SPSC study has path-scoped ThreadSanitizer qualification.
- Required CI validates the active tree with GCC and Clang.

## What this release is not

This is not a resurrection of libcoda as a utility library and does not make every study a supported reusable API.

The studies are evidence. Promotion is exceptional and consumer-driven.

## Version lineage

The repository still contains the historical 2015 `0.5.1` / `libarg3-0.5.1` prerelease.

That tag predates Seamwork. To avoid implying a semantic-version downgrade, this release uses:

```text
seamwork-0.1.0
```

Project version remains `0.1.0`.
